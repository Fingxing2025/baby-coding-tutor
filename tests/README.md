# 三个真实项目与解释深度回归

这是多轮项目测试，不是检查 AI 能不能背出 Skill 内容。测试者最好就是目标用户；旁边可有一个观察者记录证据。没有观察者也能自己做。

## 准备

1. 运行 `python3 scripts/manage.py prepare 1 --dest "/一个不存在的目录"`；测试 2/3 改编号即可。脚本不需要额外 Python 包。
2. 在 Codex 打开新目录。把 `TASK.md` 的开场提示发给它；确认使用 `baby-coding-tutor`，无法自动发现时直接指定 `.agents/skills/baby-coding-tutor/SKILL.md`。
3. 观察者在本仓库对应 `TEST.md` 看用户干预脚本，不将整份测试答案作为提示发给 AI。Test 3 原始故障放在新目录中，可复现后交给 AI 诊断。
4. 每轮保留对话与工具动作的顺序，保存项目文件差异。可在测试目录初始化 Git 方便记录，但这是观察工具，不要求学生先学 Git；也可以逐轮复制快照。

## 运行

用户根据理解程度说“继续 / 跳过 / 再讲白一点”。观察者在合适的概念出现时执行测试脚本，不必照秒表或强迫 AI 说特定字句。AI 已解释过某概念就测试回忆边界，没出现就等实际需要再问，不能诱导它建立无关课程。

默认一轮是一次用户消息到下一次用户消息；工具调用次数、AI 自己写的“第 2 步”不能重置额度。不要让观察者悄悄修项目或替 AI 写完；否则本次运行无效。

每个测试都应继续到约定项目完成或明确受阻。只看第一轮不能证明“教完项目也完成”。若连续两轮只有泛泛讲解、没有施工/诊断/验证，而且用户一直在要求继续，记录进展失败。

这个进展要求针对用户已选择的共同开发任务。单纯“教我什么是 Skill”可以先解释，不需要为了测试新建应用；用户选择实际制作后，再检查真实施工和验证。

## 记录与判定

复制 [记录表](SESSION-RECORD.md)，使用 [验收标准](ACCEPTANCE.md)。填写真实的轮次、文件、操作、输出；未触发行为写“未观察”，不要自动算通过。项目功能和教学行为分别记录，两边均通过才算整体通过。

至少完成三个项目各一次真人多轮测试；若用模型扮演学生，另标“模拟”，不能替代目标大学生的实际体验。模型不同、工具权限不同可能影响表现；记录宿主、模型、日期和环境。

为了验证跳过后不重复和召回权，Test 3 必须有“先跳过 Promise → 后面问 await → 再次跳过”的实际对话。为了验证全局地图，可在每个项目中途询问“我们现在做到哪了？”。

## Test 4：学习并创建 Skill

[行为回归脚本](behavior/04-teach-skill.md)复现“代码很少，但关键解释仍在施工之后”的问题。它先测试纯概念理解，再由用户选择创建最小 Skill，随后触发降层、跳过和实际试用。

按脚本准备独立空项目并安装 tutor；不使用 `prepare 4`，准备工具仍只支持原来的三个项目。观察者按真实对话和工具先后顺序判断解释深度，不检查固定句数、措辞或段落标题。记录格式校验、宿主发现和实际调用的不同证据，不能把其中一项当成全部通过。

这份脚本用于重复验收；[一次模型试跑记录](../docs/TEACHING-SIMULATION-v0.1.1.md)只验证了局部行为，正式宿主发现/调用与真人体验仍待执行。先控制 tutor 发现和校验环境，再评价教学；找不到 Skill 或缺少校验依赖单独记录，避免与解释失败混在一起。

## 触发边界（另开空对话即可）

| 提示 | 预期 |
| --- | --- |
| “使用 $baby-coding-tutor 带我做一个网站” | 显式启用 |
| “我会 C++，不会做项目，想边做边学一个网站，每次一小步” | 描述应匹配共同学习任务；记录是否自动选择 |
| “直接帮我实现这个接口，不需要讲解” | 不自动启用教学节奏 |
| “解释这五行 C++ 算法” | 不自动变成项目教学 |
| “用 baby-coding-tutor 教我什么是 Skill” | 显式启用教学方式，先满足概念解释，不擅自创建项目 |

触发失败要单独记录；手动指定入口成功不等于自动发现通过。

## 自动检查能做什么

`python3 -m unittest discover -s tests -p 'test_*.py' -v` 验证分发脚本、复制完整性、冲突保护、单目录 ZIP 和 Test 3 的 HTTP 故障。所有数据写到临时目录，只短暂监听本机的随机空闲端口，结束会关闭。它不调用任何付费模型、不发消息，也不执行三套完整教学或 Test 4 的多轮行为回归。

手动复现 Test 3：在准备后的目录执行 `python3 server.py 8000`，打开 `http://127.0.0.1:8000`，点击“加载笔记”。服务用 `Ctrl+C` 停止；端口被占用就换 `8001` 并打开对应地址。只有点击产生的实际页面现象才算浏览器证据，HTTP 检查单独标注。
