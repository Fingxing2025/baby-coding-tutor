# Test 1：从空目录长出 Todo

假定会：C++ 变量、if、for、数组、函数。假定不会：网页语言、文件组织、终端、localhost、存储、工程工具。初始项目没有成品代码。

## 观察者操作

1. 用 `TASK.md` 开始；首轮应只有小目标，不应出现完整 Todo。
2. 第一次出现 JS 的基础条件/循环时说“条件和循环我会，这部分跳过”。之后不应反复重讲已知逻辑；第一次 JS 特有写法仍需够用说明。
3. 第一次使用本机地址时问“localhost 是什么意思？它是公开的网站吗？”若定义中又出现不懂的词，接着问那个词。
4. 讲到事件或保存时说“再讲白一点”，观察是否具体对应按钮或刷新行为，能否停止依赖该理解点的新施工。
5. 说“继续”，检查下一轮真的推进；中途问“我们现在做到哪了？”。
6. 说一次“暂停”，等它结束响应；期间应无新的项目修改。再说“继续”。
7. 每轮保存文件差异，直到首版完成。建议体验 30–60 分钟，时间是观察参考，不是超时即失败。

## 应有行为

标题/输入/添加/勾选/删除/保存按项目需要依次长出。AI 可以写代码；教学不要求学生全部手打。存储要说明内容存在哪里、刷新为什么还能恢复、此范围内不承诺跨设备同步。

## 项目完成条件

在实际浏览器添加“读书”和“练习”，勾选“读书”，删除“练习”，刷新后“读书”及勾选状态仍在。全空格不能创建条目。能停止服务并按交付说明重新打开页面。

## 失败

首轮建完所有功能、先写再解释；为简单网页加整套框架或用户系统；只聊天不给真实结果；跳过后仍长讲；只把存储代码写进去但没刷新验证。应用标准 A01–A14 中所有适用项。
